CenaTrack: Asistente Inteligente para Cenabastos

CenaTrack es una solución que permite realizar consultas rápidas y precisas sobre la información contenida en documentos relacionados con el mercado de Cenabastos. El sistema procesa documentos (como archivos PDF de estado y precios de productos), extrae fragmentos relevantes, los indexa en una base de datos vectorial (ChromaDB) y expone una API que permite a una aplicación móvil obtener respuestas contextuales basadas únicamente en la información proporcionada.

Ver Objetivos

🎯 Objetivos del Proyecto

Objetivo General

Diseñar e implementar un asistente conversacional que responda preguntas específicas utilizando únicamente la información contenida en los documentos proporcionados y almacenados en una base de datos vectorial local.

Específico 1: Ingestión

Construir un pipeline de ingestión que lea documentos PDF, los divida en fragmentos y genere embeddings para su indexación en ChromaDB.

Específico 2: API

Implementar una API REST (FastAPI) que consulte la base de datos vectorial y devuelva respuestas coherentes para la aplicación móvil.

Específico 3: Interfaz

Desarrollar una interfaz móvil (React Native / Expo) que permita enviar consultas y visualizar respuestas en formato de chat.

💡 Justificación y Valor

Transformando la información no estructurada en conocimiento accesible para el mercado.

El Problema y la Solución

En entornos de comercio mayorista, el acceso rápido a la información (precios, disponibilidad, especificaciones) es crucial. Muchas fuentes se encuentran en documentos no estructurados o PDFs que no son fácilmente consultables en tiempo real. CenaTrack propone transformar estos documentos en una base de conocimiento consultable semánticamente, reduciendo tiempos de búsqueda y minimizando errores humanos.

La solución se justifica por su capacidad de estandarizar el acceso a la información documental y proporcionar respuestas precisas con base únicamente en fuentes proporcionadas por el usuario (principio de confianza en la fuente).

Impacto Esperado

  • Acceso inmediato a precios y especificaciones desde dispositivos móviles.
  • Consultas confiables basadas en documentos verificados.
  • Reducción del tiempo de búsqueda y mejora en la toma de decisiones.
  • Interfaz móvil accesible para diferentes actores del mercado.

⚙️ Metodología de Desarrollo

Un proceso estructurado desde la investigación inicial hasta la evaluación final del sistema.

🔬

Fase 1: Investigación

Revisión de fuentes, selección de modelos de embeddings y definición del flujo de ingestión. Evaluación de herramientas clave: LangChain, ChromaDB y modelos de embeddings.

💻

Fase 2: Desarrollo

Implementación del pipeline: carga de PDF, segmentación de texto (text splitter), generación de embeddings locales y persistencia en ChromaDB. Desarrollo de la API con FastAPI.

🚀

Fase 3: Implementación

Despliegue local del backend con Uvicorn, exposición temporal mediante Ngrok para pruebas y desarrollo del frontend en React Native (Expo) con la interfaz tipo chat.

✅

Fase 4: Evaluación

Pruebas funcionales: verificación de la precisión en la búsqueda semántica, pruebas de casos de uso y análisis de desempeño de la base de datos vectorial.

🏆 Resultados Obtenidos

Logros alcanzados en la construcción del asistente inteligente CenaTrack.

Solución Operacional

Se construyó un asistente de texto que consulta una base de conocimiento derivada de documentos PDF indexados en ChromaDB. La aplicación móvil realiza solicitudes a una API (FastAPI) y muestra respuestas contextuales en una interfaz tipo chat, demostrando la viabilidad de la consulta semántica local.

Indicadores Clave de Éxito

  • Indexación Exitosa: Documentos PDF procesados y almacenados en ChromaDB.
  • API Funcional: Endpoint REST que responde a consultas con fragmentos de texto relevantes.
  • Aplicación Móvil: Interfaz (Expo / React Native) capaz de enviar consultas y recibir respuestas de la API.
  • Búsqueda Semántica: Verificación de la precisión en la recuperación de información.

Del Caos a la Coordinación

Cenabastos es vibrante pero complejo para quien le visita por primera vez. Damos claridad y asistencia a los retos logísticos y geograficos que enfrenta cada día.

El Reto Diario

Navegar por un mercado logísticamente complejo e informal conduce a ineficiencias, pérdida de tiempo y oportunidades perdidas. La falta de información en tiempo real dificulta y genera estrés la coordinación entre proveedores, compradores y transportistas.

Nuestra aplicación centraliza la información y la comunicación, proporcionando una vista panorámica en vivo de la actividad del mercado. Le proporciona los datos necesarios para navegar de manera eficiente, conectarse sin problemas y hacer crecer su negocio.
